# SPDX-License-Identifier: Apache-2.0

# One word per line, most frequent first. The Zipf value of a word is derived
# from its 1-based rank as  zipf = 8 - log10(rank), which reproduces the
# familiar scale (zipf 7 ≈ "the", zipf 5 ≈ rank 1000, zipf 4 ≈ rank 10000)
# closely enough for a reward band. Words absent from this list are treated as
# uncommon-but-real (see craft.UNKNOWN_WORD_ZIPF).
#
# Why a bundled list rather than the `wordfreq` package: the engine must work
# with no network and inside a PyInstaller bundle that already carries model
# runtimes, and wordfreq's data would add tens of megabytes for a metric that
# only needs to place a word in a band. craft._zipf_for_word is the single seam
# to swap in a wordfreq-backed provider later.
#
# Lines beginning with # are comments; blank lines are ignored.
